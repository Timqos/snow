# Snow / FM-1: узгоджені вимоги

Власна прошивка FM-1 на базі Skiff/Felucca. Шість незмінних ролей:
KICK / SNARE / HAT / PERC / BASS / CHORD, по 10 пресетів відповідного
інструмента. Повна глибина ручного синтезу залишається: алгоритми, хвилі,
осцилятори, ADSR, pitch/FM envelopes, два LFO, модуляція та окремі FX.
Роль каналу не перемикається; радикальна ручна трансформація звуку дозволена.

Генератор має щоразу створювати нові ритми та мелодії, характерні для ролі.
IDM, electronica, breakbeat, DnB, deep, ambient та інші напрями — музичні
впливи всередині алгоритму, без меню вибору жанру й фіксованого шаблону на жанр.
Grbox.html користувача — приклад поведінки GEN RND, GEN PARM, PARM AMT, CLEAR,
а не вимога переносити його вісім семплерних каналів чи інший зайвий функціонал.
GEN RND створює ноти, ритм, velocity; GEN PARM змінює локи поверх нот.
Перкусія має грати ноти в тональності. Рідкі ретригери та тріолі хета/перкусії
не повинні перетворювати кожну фразу на безперервний roll.

Піксельна мова оформлення поширюється на всі сторінки, меню та діалоги.
HOME відповідає новому PDF: один обраний канал, три панелі керування та осцилограма внизу. Картка містить роль, назву пресету, патерн, оригінальну піксельну
іконку і назву/відсоток останнього зміненого параметра. Іконки анімуються
по-різному при обертанні параметрів, із незмінними межами та положенням.
Деталі іконки керуються значенням параметра; форма залишається за новими PNG-зразками;
після зупинки вона зберігається, зворотне обертання відтворює ті самі стани.
Усі іконки забарвлені активним кольором теми. Системні кольори змінюють увесь UI: cyan, blue, orange, green та інші.

MIXER та PATTERNS показують усі шість каналів одночасно. HOME показує один обраний канал. Утримання SEQ відкриває шість колонок патернів по 8 видимих слотів;
OCT± перемикає A–H / I–P. K1–K4 керують каналами 1–4, ALGORITHM — басом,
PRESETS — акордами. Патерни каналів незалежні, звук каналу зберігається.

Утримання GLO відкриває шестиканальний мікшер із рівнями та клавішами
MUTE/SOLO. Призначення шести енкодерів таке саме. Перші шість чорних
клавіш — MUTE, перші шість білих — SOLO; ALL, FILL, TAP доступні поруч.
Логіка Tessera — орієнтир взаємодії, оформлення Snow власне.

Візуальні оновлення виконуються в головному циклі, поза аудіоперериваннями.
Необхідні перевірки бюджетів RAM, синтезу, FX та коректності секвенсора;
перевірку тріску/затримок на фізичному FM-1 не можна замінити браузером.

Перша сторінка EDIT / MACROS: OCT+ рандомізує всі параметри всіх сторінок
EDIT тільки обраного каналу, зі звичайним UNDO. TARGET генератора за
замовчуванням означає вибраний канал і показує його коротку назву; загальна
генерація позначена ALL. Решта алгоритму генерації Snow 0.4 збережена.

RANDOM EDIT генерує новий звук інструмента, а не незалежні повнодіапазонні
значення. Співвідношення осциляторів, регістр, огинаючі, шум, фільтр і
модуляція узгоджуються з роллю; FX мають помірні рівні та зворотні зв’язки.
Акорд залишається поліфонічним, бас низьким і тональним, перкусія грає ноти.
Нові звуки обчислюються з великого простору параметрів, без циклу фабричних
пресетів. Ручне редагування зберігає повні діапазони.

Сторінка симулятора англомовна: девайс, одразу під ним Install із бекапом
та застереженнями, далі опис прошивки й довідник кнопок. Окремі вебтаблиці
та конструктор звуків вилучені. Інсталятор використовує пакет саме Snow
FM-1, перевіряє хеш і модель, підтримує бекап та явне підтвердження запису.

Старт Snow: наданий піксельний логотип 7×7 із порожнім центром поступово
збирається на екрані; напис Snow зʼявляється під ним. Разом близько 1,5 с,
потім HOME. Обмежена частота оновлення, без роботи в аудіоперериванні.
Той самий знак і назва Snow Firmware у шапці сайту; стислий опис перед
симулятором, встановлення й довідник після нього.

Перед завершенням релізу обовʼязковий аудит встановлення й відкату: незмінність
критичних областей і завантажувача, карта флеш, CRC та модель пакета, перерваний
запис і відновлення, Snow ↔ Skiff, відповідність заводських V15/V16 стартовій
області. Програмні тести не є гарантією для фізичного FM-1: окремо фіксується
стан апаратної перевірки й зберігається шлях повернення та резервна копія.

Перша сторінка LFO: OCT+ рандомізує всі параметри обох LFO й маршрути
модуляції обраного каналу. Перша сторінка FX: OCT+ рандомізує всі параметри
усіх сторінок ефектів обраного каналу, зокрема Slicer/Duck. Звичайний
UNDO через утримання SAVE повертає попередні значення. Секвенція, локи,
інші канали й решта розділів не змінюються.

SEL: 35 скейлів, включно з усіма назвами на скріні Ableton; старі індекси
0–15 зберігаються. Перша сторінка: MODE / ROOT / SCALE / QUANTIZE.
CHORDS — акорд однією клавішею; NOTES — окремі ноти й запис власних акордів
до чотирьох нот на CH. Транспонування — на другій сторінці SEL.
CH: release за замовчуванням 2BAR на всіх заводських пресетах, реально
синхронізований із темпом. EDIT OCT+ зберігає release, як і LFO/FX random.

Уточнення 0.7.0 за PDF та погодженнями: SELECT у HOME має три позиції —
синтез / генерація / мікшер; темп не змінюється. Усі три стрілки обертаються
разом. Рамок навколо панелей немає. Ручки генерації: K1 звук, K2 ноти+локи,
K3 LFO, K4 FX; кожен клік в обидва боки — одна генерація, один Undo на ноти+локи.
Верхня панель: VOL/PAN/FLR/WDT. DJ-фільтр: 50% нейтраль, нижче LP, вище HP.
WDT: ширина всього каналу з ефектами, 0% моно / 50% початкова / 100% подвійна.
Назва пресету — під активним параметром, над іконкою. N/CHO під касетою
синхронний із SEL; на HOME CH: HOME+OCT+ перемикає NOTES/CHORDS один раз за натиск. Одиночний OCT+ змінює октаву одразу; HOME без комбінації зберігає системні налаштування.
GLO зберігає чинний режим темпу без обов’язкового утримання кнопки.
Іконки взяті з шести PNG; анімація локальна, без зміщення та деформації силуету.
