# Snow / FM-1: узгоджені вимоги

Власна прошивка FM-1 на базі Skiff/Felucca. Шість незмінних ролей:
KICK / SNARE / HAT / PERC / BASS / CHORD, по 10 пресетів відповідного
інструмента. Повна глибина ручного синтезу залишається: алгоритми, хвилі,
осцилятори, ADSR, pitch/FM envelopes, два LFO, модуляція та окремі FX.
Роль каналу не перемикається; радикальна ручна трансформація звуку дозволена.

Генератор має щоразу створювати нові ритми та мелодії, характерні для ролі.
IDM, electronica, breakbeat, DnB, deep, ambient та інші напрями — музичні
впливи всередині алгоритму, без меню вибору жанру й фіксованого шаблону на жанр.
Grbox.html користувача — приклад поведінки GEN RND, GEN PARM, PARM AMT, CLEAR,
а не вимога переносити його вісім семплерних каналів чи інший зайвий функціонал.
GEN RND створює ноти, ритм, velocity; GEN PARM змінює локи поверх нот.
Перкусія має грати ноти в тональності. Рідкі ретригери та тріолі хета/перкусії
не повинні перетворювати кожну фразу на безперервний roll.

Піксельна мова оформлення поширюється на всі сторінки, меню та діалоги.
HOME відповідає другому ескізу користувача: шість карток 3×2 та осцилограма
внизу. Картка містить роль, назву пресету, патерн, оригінальну піксельну
іконку і назву/відсоток останнього зміненого параметра. Іконки анімуються
по-різному при обертанні параметрів, із незмінними межами та положенням.
Форма іконки безпосередньо відповідає 0–100% останнього зміненого параметра;
після зупинки вона зберігається, зворотне обертання відтворює ті самі стани.
Усі іконки забарвлені активним кольором теми. Системні кольори змінюють увесь UI: cyan, blue, orange, green та інші.

Усі огляди каналів, включно з HOME, MIXER та PATTERNS, показують усі шість
одночасно. Утримання SEQ відкриває шість колонок патернів по 8 видимих слотів;
OCT± перемикає A–H / I–P. K1–K4 керують каналами 1–4, ALGORITHM — басом,
PRESETS — акордами. Патерни каналів незалежні, звук каналу зберігається.

Утримання GLO відкриває шестиканальний мікшер із рівнями та клавішами
MUTE/SOLO. Призначення шести енкодерів таке саме. Перші шість чорних
клавіш — MUTE, перші шість білих — SOLO; ALL, FILL, TAP доступні поруч.
Логіка Tessera — орієнтир взаємодії, оформлення Snow власне.

Візуальні оновлення виконуються в головному циклі, поза аудіоперериваннями.
Необхідні перевірки бюджетів RAM, синтезу, FX та коректності секвенсора;
перевірку тріску/затримок на фізичному FM-1 не можна замінити браузером.

Перша сторінка EDIT / MACROS: OCT+ рандомізує всі параметри всіх сторінок
EDIT тільки обраного каналу, зі звичайним UNDO. TARGET генератора за
замовчуванням означає вибраний канал і показує його коротку назву; загальна
генерація позначена ALL. Решта алгоритму генерації Snow 0.4 збережена.
