Use desktop Chrome or Edge. On STATTIC S1:

  1. Press STOP. Hold HOME, turn SELECT to AUDIO, then set USB SERIAL → ON.
  2. Press HOME to close the menu and save the setting.
  3. Fully power off the FM-1 and disconnect USB. Power it on again and reconnect USB. Unplugging only the cable while the FM-1 stays on does not enable the serial interface.
  4. Press Connect USB & start log and choose the FM-1 / STATTIC serial port. Close other serial terminals first.

USB SERIAL is OFF by default. If the chooser says “No compatible devices found”, first check this setting and restart sequence. USB MIDI working does not mean that USB SERIAL is enabled.

The browser asks for a USB port only when you press Connect.

One useful test.

  1. Connect and let capture start. Play DR + BS + SY without CH for a short baseline.
  2. Enable CH and play the combination that rasps. Press Mark rasp when you hear it; add a short note if useful.
  3. Press STOP on the FM-1 and let one more sample finish (or press One snapshot). Then Pause capture, save the JSON log and attach it to the conversation.

The log stays in this tab until you save it. Reloading loses unsaved data. It includes diagnostic text, sound/preset names and notes you enter; nothing is uploaded automatically.
