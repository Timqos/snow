1. Connect and back up

Use Chrome or Edge. Connect only the FM-1 you want to update. Stop the sequencer and close other MIDI applications. The package is checked against the model and its SHA-256.

A full automatic backup is not available for the current firmware. Export its data with its own tools before installing. The new STATTIC format on SLOOP is not compatible with projects from the old STATTIC/Skiff.

Install the factory firmware
The FM-1 V15 or V16 factory package must match the device’s boot code; do not bypass the installer’s check. The factory firmware cannot open STATTIC projects. Keep your backup and the firmware that made it.
If an update was interrupted
Leave the power and USB connected. Open the installer with the same package and wait for the update loader to connect. Finish the original update first, then go back to the factory firmware. After a successful write, wait for the restart and check ABOUT. If neither a working firmware nor the loader is reachable, use the built-in UBOOT and the official M-VAVE utility as the manufacturer describes for the FM-1. Do not use a package for another model, or --force.
