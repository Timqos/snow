Install original factory firmware.

Return your M-VAVE FM-1 to its original firmware using an unmodified manufacturer package. Save your STATTIC music before returning.

Match the device’s original version. An FM-1 with a V15 startup head needs V15; a V16 head needs V16. The running firmware checks the startup head before switching to the factory updater. A rejected version is not forced onto the device.

1. Select the original file.

Get original V15 from M-VAVE’s repository or V16 from M-VAVE’s official downloads. Choose the version that matches the FM-1. The filename alone does not identify the version.

The browser checks the exact original package SHA-256 and layout locally. Modified packages and SMK-37 files are rejected. The selected file is not uploaded to a server.

2. Connect and back up.

Use desktop Chrome or Edge. Stop playback, connect only the intended FM-1 directly by USB, close other MIDI applications and keep reliable power connected. Connecting exports and validates a complete backup where supported; it does not install firmware.

No automatic complete backup is available from this firmware. Export your music with that firmware’s own tools before continuing. Finish any interrupted firmware update before attempting a factory return.

3. Install factory firmware.

Firmware changes are at your own risk and responsibility. Updates can lose data or require physical recovery if interrupted. After installation or an interrupted update.
Allow the FM-1 to restart. Keep your backup for reinstalling the firmware that created it. Do not restore STATTIC projects into factory firmware.
