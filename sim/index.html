REAL FIRMWARE UI + DSP / BROWSER

STATTIC FM-1

The FM-1 in your browser, running this firmware’s own code. Knobs: drag up or down, or use the mouse wheel. Buttons and keys can be held. A long OCT+ on HOME 1 of the CH channel switches between note and chord.

Audio starts after you press the button.

Computer keyboard: keys Z…/ and S D G H J L ; play the lower keys, Q…Y with 2 3 5 6 the upper ones; Space is PLAY.

The simulator runs the firmware’s own C code (synthesis, samples, sequencer, HOME and the other windows) compiled for the browser. It is rebuilt from the same source with every firmware put on the install page; build.json names the build it runs. A browser does not reproduce the hardware’s speed or audio interruptions. Nothing here changes a connected device.

STATTIC 0.9.0-S1 · FM-1 · based on SLOOP 2.8.5.
