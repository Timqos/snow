REAL FIRMWARE UI + DSP / BROWSER

STATTIC FM-1

Knobs: scroll wheel, drag up/down, or the −/+ buttons. Buttons can be held. A long OCT+ on HOME 1 of the CH channel switches between note and chord.

Audio starts after you press the button.

The simulator runs the firmware’s own C code (synthesis, samples, sequencer, HOME and the other windows) compiled for the browser. It is built separately from the FM-1 firmware and can lag behind the latest install: the build it runs is recorded in build.json. A browser does not reproduce the hardware’s speed or audio interruptions. Nothing here changes a connected device.

STATTIC 0.9.0-S1 · FM-1 · based on SLOOP 2.8.5.
