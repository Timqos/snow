BEFORE YOU BEGIN

One device. A reliable connection.

  1. Use desktop Chrome or Edge with Web MIDI SysEx support. Connect only the FM-1 you intend to update, directly by USB. Use a reliable data cable and stable power.
  2. Stop playback. Close DAWs, editors and any other application using the MIDI port. Disconnect other MIDI hardware.
  3. Save your music to your computer. A supported Snow/Skiff/Felucca device can export a complete backup below. Stock firmware or other forks may need their own backup/export tool.
  4. Keep a copy of the current firmware and its restore instructions. Snow has a different instrument model: another firmware’s sounds/projects may not translate. Backups from it are for rollback to that firmware.
01 / CONNECT & BACK UP

Keep a way back.

The firmware package is checked before connecting. Connecting does not write firmware. If a complete backup is supported, it is validated and downloaded before the install button can be used.

This firmware cannot export a complete Snow/Skiff backup, or the device is already in its update loader. No automatic backup has been made. Export with the original firmware’s own tools first. A loader cannot recover music that was not backed up before the interruption.

INSTALLATION CHECKLIST
Install Snow, step by step.
  1. Before changing firmware, record the currently installed version and the original factory version, if known. Keep the matching original package and its instructions. If the original factory version is unknown, establish a compatible recovery route before proceeding; do not assume the latest factory file will match.
  2. Export your music and save the backup outside the device. Use Connect & back up above for supported firmware, or the current firmware’s own export tools. Check that the downloaded files exist and keep an extra copy.
  3. Read the risk notice, connect only the intended FM-1 directly by USB, stop playback and close other MIDI software. This page verifies the exact Snow package and hash automatically.
  4. Connect and back up, review the detected device and existing acknowledgements, then select Install Snow. Keep USB, power and the browser connected until completion; do not start a second updater.
  5. Allow the device to restart. Check the installed version in MENU / ABOUT. When coming from another firmware, start a new Snow project. Keep all previous backups and the matching original firmware.


RETURN TO FACTORY FIRMWARE
Use the factory version that matches the device.
Install factory firmware
The dedicated factory installer validates your original V15/V16 file, backs up supported firmware, and uses the existing model and startup-head checks. The Snow installation flow above remains separate.
This Snow installer installs Snow only. Do not feed a factory package into this page. The FM-1 retains its existing bootstrap: a unit with a V15 startup head needs the matching original V15 package; a V16 head needs matching V16. The filename alone does not identify compatibility. Use your recorded pre-install version, retained original package or manufacturer guidance. If the original version is unknown, stop and establish the correct package rather than guessing.
  1. While Snow still runs, save a fresh Snow backup for any music you want to keep. Also retain the backup made before installing Snow. Stop playback and close other MIDI applications.
  2. Obtain an unmodified matching factory .fwsc from your saved original or M-VAVE’s official downloads. Follow the manufacturer’s return/update instructions where they support the currently running firmware.
  3. For a running Snow/Skiff/Felucca device, the repository’s established USB-MIDI installer also supports the recognised original FM-1 V15/V16 packages. On a desktop computer, download/extract the source repository, install Python 3, and run the commands below from the repository folder. Replace the example path with your matching factory file; use your system’s python3 command if needed.
python -m pip install mido python-rtmidi
python tools/fm1_install.py --info
python tools/fm1_install.py "/path/to/matching-factory.fwsc"
Review the reported device/package and the installer’s confirmation, then keep power and USB connected until it finishes and the FM-1 restarts. Do not use --force to bypass validation or treat an incompatible file as compatible. If the package or startup head is rejected, stop; do not keep trying other versions. The factory-return route has passed software checks with real packages, but has not been qualified on a physical FM-1 for this release.
After the factory firmware boots, verify its version and restore the original factory backup with the matching factory tools, if supported. A Snow archive is for Snow and is not a factory-compatible restore image. If Snow no longer boots or the loader does not answer, use the recovery guidance below; an ordinary reinstall may not be possible.


RECOVERY & ROLLBACK
If something goes wrong.
  • Do not interrupt a write. Follow the status message and allow re-enumeration of the MIDI device. The updater can resume writes when the same loader reconnects.
  • If the loader still answers after an interruption, reopen this installer, connect again and resume only if you already saved a backup. It cannot make a backup from update mode.
  • If the device no longer starts or exposes its loader, software-only recovery may be unavailable. Read the FM-1-transporter recovery documentation; physical recovery may be needed.
  • To roll back, reinstall the firmware that created your archive and restore with its matching tools. Keep archives untouched. This installer does not automatically convert or restore another firmware’s data.
  • For official firmware, follow M-VAVE’s instructions and use the stock version matching the device’s startup/bootloader. A different .fwsc is not a guaranteed recovery path.
Read the installation and rollback audit before changing firmware. The preserved startup head determines whether the matching factory package is V15 or V16. Use another firmware’s verified package and matching installer; this installer installs Snow only. Software checks have passed; physical qualification is still pending.
After a successful install, check the version in MENU / ABOUT. Start a new Snow project when moving from another firmware. Keep your previous backup even if the new firmware appears to work.
Report a problem with the source version, device’s previous firmware and the update log. Do not include private musical backups in a public issue.
