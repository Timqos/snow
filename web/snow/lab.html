SNOW / FM-1

KICK · SNARE · HAT · PERC · BASS · CHORD. По 10 пресетів свого інструмента на канал. Усі алгоритми, хвилі та огинаючі доступні для ручного перетворення звуку.

Увімкни звук → завантаж демо → PLAY. Демо замінює поточні кроки. Або відкрий ГЕНЕРАТОР та натисни GEN RND.

KICK / CH 1

НЕЗАЛЕЖНІ ПАТЕРНИ КАНАЛІВ

Кожна ручка під своєю колонкою перемикає тільки цей інструмент. На пристрої: утримуй SEQ; ALGORITHM — бас, PRESETS — акорди; OCT± — A–H / I–P. Активний патерн підсвічений, запланований — із пунктиром. Крапка означає збережений або поточний непорожній патерн.

Новий слот порожній. Вибери його, дочекайся запуску під час гри й створи варіацію у ГЕНЕРАТОРІ. Звук каналу зберігається при перемиканні патернів.

GEN RND — нові ноти, ритм і velocity. GEN PARM — нові параметр-локи поверх цього рисунка; ноти та velocity залишаються. PARM AMT — кількість і глибина локів. CLEAR — прибрати кроки та локи. Кожне натискання дає новий результат; музичні напрями змішуються всередині генератора.

Висота смуги — velocity; крапка — параметр-лок; ×2/3/4 — ретригер. Для хета й перкусії прикраса звучить не частіше одного кроку кожного другого такту. Перкусія, бас і акорди враховують тональність. Density: 0 — тиша, 100 — усі кроки. EVOLVE — нова фраза кожні 1/2/4 цикли.

Окремі буфери й налаштування кожного каналу. Delay: час або tempo sync, feedback, tone, width. Reverb: room/hall/plate, decay, damping, predelay. Chorus: rate, depth, feedback. Tape та Bitcrush — зі своїми MIX і параметрами. Значення MIX 0 вимикає ефект; BYPASS вимикає весь ланцюг.

Увімкни звук, щоб відкрити параметри синтезу.

Послухати нові барабанні пресети

По 10 сухих ударів у фабричному порядку, без ефектів. Один удар кожні 1,3 с. Це рендер C-движка FM-1.

Кнопки FM-1 та збереження

SEQ → SEQ GEN. OCT+ — GEN RND, OCT− — GEN PARM, SAVE + OCT− — CLEAR. TARGET: KK / SN / HH / PR / BS / CH або ALL. За замовчуванням — поточний канал. K4 — PARM AMT. Під генератором завжди видно справжню сітку кроків.

EDIT → перша сторінка MACROS → OCT+: рандом усіх 96 параметрів усіх сторінок EDIT поточного каналу, включно з FX. Утримання SAVE — UNDO. На інших сторінках OCT+ має звичайну дію.

Іконки HOME показують положення останнього зміненого параметра: 0% — початкова форма, 100% — кінцева. Форма залишається на місці після зупинки ручки та використовує колір теми.

Утримуй SEQ: усі шість каналів на дисплеї. K1–K4 перемикають патерни каналів 1–4; ALGORITHM — басу, PRESETS — акордів. OCT± — A–H / I–P.

Утримуй GLO: ті самі шість ручок керують рівнями. Перші шість чорних клавіш — MUTE, білих — SOLO, E4 — ALL, F4 — FILL, G4 — TAP. GLO + OCT− повертає рівні та мʼюти. GLO + EDIT + K1–K4 — Control All; GLO + EDIT + OCT− — маска каналу. GLO + SAVE — Temp Save; GLO + HOME — Reload all; GLO + OCT+ — Reload channel. Звичайний SAVE зберігає проєкт.
