SNOW / FM-1 · 0.2

Шість каналів. Будь-який звук.

На кожному каналі — всі алгоритми, хвилі й огинаючі. Стартові звуки можна повністю перебудувати: кік → снейр → хет → синтезатор → FX.

Увімкни звук → завантаж демо → натисни PLAY на панелі нижче. Демо замінює поточні кроки всіх каналів.

CH 1 / SOUND DESIGN

Генерація змінює обраний канал. У GENERATIVE SEQUENCER нижче: ритм / мелодія / разом, density, syncopation, seed, contour, scale та автоматичне EVOLVE. Новий слот патерна спочатку порожній.

Увімкни звук, щоб відкрити параметри синтезу.

PATTERN A–P перемикається незалежно для кожного каналу; під час гри діє квантування запуску. На пристрої: SAVE → PATTERNS 1–4 / 5–6, кожна ручка керує своїм каналом. SEQ → GEN… → OCT+ створює варіацію. EDIT → сторінки параметрів.

Control All, збереження та керування

Позначки ALL визначають канали для Control All. Утримуй GLO та крути K1–K4; Shift-клік фіксує GLO. GLO + SAVE — Temp Save, GLO + HOME — Reload, GLO + OCT− — маска каналу, GLO + OCT+ — Reload одного каналу. Ручки панелі тягни вгору й униз. Temp Save зберігає стан у RAM до перезавантаження; звичайний SAVE зберігає проєкт.

Патерни зберігають ноти й locks; звук задається окремо для каналу. Канали мають власні filter, drive та insert. Chorus/delay/reverb поки використовують спільні sends. Це прототип; перевірка на фізичному FM-1 ще попереду. Базовий Skiff · Можливості й перевірки.
