SNOW / FM-1 · 0.3

Свої інструменти. Вільний синтез.

KICK · SNARE · HAT · PERC · BASS · CHORD. По 10 пресетів свого інструмента на канал. Усі алгоритми, хвилі та огинаючі доступні для ручного перетворення звуку.

Увімкни звук → завантаж демо → PLAY. Демо замінює поточні кроки. Або відкрий ГЕНЕРАТОР та створи грув обраного стилю.

KICK / CH 1

НЕЗАЛЕЖНІ ПАТЕРНИ КАНАЛІВ

Кожна ручка під своєю колонкою перемикає тільки цей інструмент. На пристрої: утримуй SEQ; OCT+ — канали 5–6, OCT− — A–H / I–P. Активний патерн підсвічений, запланований — із пунктиром. Крапка означає збережений або поточний непорожній патерн.

Новий слот порожній. Вибери його, дочекайся запуску під час гри й створи варіацію у ГЕНЕРАТОРІ. Звук каналу зберігається при перемиканні патернів.

Один стиль, шість різних ролей: кік тримає основу, снейр — backbeat/ghost notes, хет — пульсацію й дроблення, перкусія — додатковий ритм, бас — лінію, акорди — гармонію. Стиль і параметри нижче можна задати окремо для вибраного каналу.

Density 50 — типова щільність стилю для інструмента; 0 — тиша, 100 — усі кроки. Complexity додає ghost notes і дроблення; Variation — відхилення від опорних долей; Human — живу нерівність. Seed повторює результат. EVOLVE створює варіації кожні 1/2/4 цикли.

Окремі буфери й налаштування кожного каналу. Delay: час або tempo sync, feedback, tone, width. Reverb: room/hall/plate, decay, damping, predelay. Chorus: rate, depth, feedback. Tape та Bitcrush — зі своїми MIX і параметрами. Значення MIX 0 вимикає ефект; BYPASS вимикає весь ланцюг.

Увімкни звук, щоб відкрити параметри синтезу.

Керування пристроєм і збереження

EDIT — параметри синтезу та ефектів; SEQ → GEN STYLE — стиль і варіативність. OCT+ на GEN — варіація каналу, OCT− — ансамбль у поточному стилі. Утримання SEQ — сітка патернів; K1–K4 відповідають своїм каналам. OCT+ перемикає сторінки каналів 1–4 / 5–6, OCT− — слоти A–H / I–P. Shift-клік у браузері утримує кнопку.

Позначки ALL визначають канали для Control All. GLO + K1–K4 — макрозміни, GLO + SAVE — Temp Save, GLO + HOME — Reload, GLO + OCT− — маска, GLO + OCT+ — Reload одного каналу. Temp Save існує в RAM до перезавантаження; звичайний SAVE зберігає проєкт. Прошивка ще потребує перевірки на фізичному FM-1. Skiff baseline · Можливості та перевірки.
