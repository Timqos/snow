INSIDE STATTIC

Six instruments. Five clear HOME pages.

One role. Many voices.

Kick · Snare · Hat · Pitched percussion · Bass · Chord. Ten factory sounds per instrument. Three oscillators; FM pair, chain, parallel, ring, additive and fold algorithms; sine, triangle, saw, square, pulse and organ waves.

Full synthesis, ADSR, pitch/FM envelopes, filters, two LFOs and modulation remain available. CH starts with a tempo-synchronised two-bar release.

Generate, then make it yours.

Generate a new phrase with parameter locks, a new instrument sound, LFO settings or an audible effect combination from HOME 2/5. The instrument roles stay fixed. Manual editing retains the full parameter ranges and synthesis architecture.

Rhythmic families are chosen internally. Bass uses melodic phrasing and tied notes; chords use harmonic movement, voicings and longer holds. There is no genre menu.

Three patterns. Six hands-on selectors.

HOME 4/5 shows all six channels and P1–P3 at once. Four parameter encoders plus ALGORITHM and PRESETS give every channel its own pattern selector. RANDOM PATT selects saved patterns; GEN RND creates new sequences.

Effects belong to each channel.

Independent delay, room/hall/plate reverb, chorus, Tape, bitcrush, drive and insert controls. The dedicated FX generator chooses an audible lead processor with bounded feedback; sound generation keeps a gentler rack to preserve the instrument body.

FIRST FIVE MINUTES

Start on HOME 1/5.

  1. Switch on the simulator. Drag an encoder or focus it and use arrow keys. Shift-click holds a button down.
  2. ALGORITHM selects KK/SD/HH/PR/BS/CH. PRESETS chooses a sound. On HOME 1/5, K1–K4 control TONE/SHAPE/SWEEP/DECAY.
  3. Turn SELECT one click right to HOME 2/5. Turn K1 for a phrase and locks, K2 for a new sound, K3 for LFO settings or K4 for effects. Each detent produces one generation. Press PLAY/STOP to listen.
  4. HOME 3/5 controls channel mixing. HOME 4/5 switches patterns. HOME 5/5 provides MUTE/SOLO and volume for all six channels.
  5. HOME SELECT never changes BPM. Tap GLO and turn SELECT for tempo. Hold HOME for system settings.

The browser runs the firmware’s C engine and interface through WebAssembly. Saves stay in this browser. Physical USB audio, external MIDI ports and hardware CPU deadlines are not emulated.

QUICK REFERENCE

Under your hands.

HOME → SELECT
SELECT browses five bounded pages. The enlarged transport strip, bar/beat, BPM, STATTIC name and battery remain visible. All bottom helpers use one enlarged 8×14 native-pixel face, including OCT commands, page navigation and every encoder assignment. Their full wording is retained and the upper HOME artwork is unchanged. The empty visualizer strip is removed. Pages 1–3 show the selected channel, preset name and pattern. Their static artwork scrolls vertically by six native rows per encoder detent and wraps continuously. Idle knobs leave it still. Drawing runs outside the audio interrupt at no more than 20 updates per second.
HOME 1/5 → SOUND
K1 TONE; K2 SHAPE; K3 SWEEP; K4 DECAY. The large PRM readout names the last macro adjusted and shows its percentage. OCT± changes octave. ALGORITHM selects channel; PRESETS chooses an instrument preset.
HOME 2/5 → GENERATE
One detent in either direction = one generation, without acceleration. K1 G/SEQ generates a phrase and parameter locks in one undo transaction. All six channels start with LENGTH 64, including after restoring an older session. The generator covers the entire current length. At 64 steps, it creates four bars with varied rhythm, bass movement and chord progression; bar 1 may repeat in bar 3, while bars 2 and 4 vary. It does not clone a 32-step half. Explicit 0%/100% density and MELODY’s existing rhythm are respected. K2 G/PRM creates a new instrument sound. K3 G/LFO generates modulation; K4 G/FX generates effects. The large label follows the generator used. During PLAY, all four knobs prepare a candidate without changing the sounding track; the latest candidate enters on the next shared bar. Several detents and different generator knobs can build one candidate before that bar, with each detent still advancing its generator. On STOP, generation applies immediately. Hold SAVE before the bar to cancel the pending batch; OCT+ in the undo window can redo it. A later pattern selection or explicit sound/pattern load replaces the pending candidate. OCT− CLEAR PT clears the selected current pattern and its locks. OCT+ CLEAR ALL clears the current patterns and locks of all six channels; other saved positions and sound settings remain. OCT± does not change octave here. Hold SAVE to undo the selected channel’s last action. While its undo window is active, OCT−/OCT+ undo/redo instead of clearing patterns. Pending pattern launches must finish before generation or clear.
HOME 3/5 → MIXER
K1 VOL: channel level. K2 PAN: left/right, centre 50%. K3 FLR: DJ filter; 50% neutral, lower cuts highs, higher cuts lows. K4 WDT: stereo width including channel effects; 0% folds to mono, 50% preserves normal stereo, 100% doubles the side component. A mono source needs SPREAD or stereo effects for width to act. The active VOL/PAN/FLR/WDT box has a numeric percentage beside it; this is the selected parameter value, not an audio meter. OCT± changes octave.
HOME 4/5 → PATTERN SW
All six channels and three patterns P1–P3 fit together. K1 → KK; K2 → SD; K3 → HH; K4 → PR; physical ALGORITHM (ALG) → BS; physical PRESETS (PRS) → CH. A filled badge marks the playing pattern; an outline marks a queued selection. During PLAY, changes wait for the next shared bar of the transport, then start from the incoming pattern’s first step, together across channels. This timing is independent of each channel’s LENGTH, DIV and SWING; USB/TRS clock follows the external transport. Choose another pattern to replace the request, or return to the playing pattern to cancel it. On STOP, pending changes apply immediately. OCT± RANDOM PATT randomly selects existing saved patterns and queues them as one group for the same bar. It never generates notes or creates empty patterns. Turning a channel’s selector to an unused position creates a new empty pattern there.
HOME 5/5 → M/S VOLUME
Six rows show channel, mute, solo, textured level bar and percentage. K1 SLT CH selects channel; K2 VOL changes that channel’s volume. K3/K4 have no assignment. The first six white keys (F3, G3, A3, B3, C4, D4) toggle the corresponding MUTE states. The first six black keys (F#3, G#3, A#3, C#4, D#4, F#4) toggle SOLO. During PLAY, mute/unmute and solo/unsolo wait for the next shared bar, together with queued patterns and HOME 2 generation. An outline around M/S marks a pending change; the fill shows the current state. Press again before the bar to cancel the request; holding does not repeat. On STOP, changes apply immediately. These physical keys do not sound or record notes here. Leaving the page keeps the queued changes and active solo; return and press its black key again to clear it. Loading a project clears pending commands and transient solo. Bars grow/shrink horizontally with volume.
ALGORITHM / PRESETS / SELECT
ALGORITHM chooses channel and PRESETS its factory sound on HOME pages 1–3 and 5. On page 4 they select BS/CH patterns instead. SELECT always chooses the HOME page. In GLO’s MIXER and GLOBAL windows, SELECT changes tempo without holding GLO, with either BPM-lock setting.
CH → NOTES / CHORDS
SEL page 1, K1 switches NOTES/CHORDS. NOTES plays and records your own chords, up to four notes; CHORDS expands one key using the chosen shape and voicing. On HOME 1/5, select CH and hold OCT+ alone for 0.7 seconds to toggle the mode once; keep HOME released. A short OCT+ tap changes octave when released. The hold changes neither octave nor page. The helper reads “OCT+ HLD N/CHO”; beside CH’s preset, A means chords and N means notes. This indicator also follows changes made in SEL. Holding HOME alone still opens settings.
EDIT → FIRST PAGE → OCT+
Generate a new sound across the selected channel’s EDIT pages. Instrument identity, sequence and other channels remain intact. CH’s selected release is preserved. Full manual algorithm, waveform and synthesis controls remain available. Hold SAVE for undo.
SEQ → SEQ GEN
OCT+: GEN RND. OCT−: GEN PARM. SAVE + OCT−: CLEAR. K1 selects channel/ALL; K2 density; K3 variation; K4 PARM AMT. GEN PARM adds locks to existing notes. PARM AMT = 0 disables generated locks. SELECT opens the remaining generation controls. Bass uses melodic phrases, tied notes and occasional slides; chords use progressions, voicings, occasional sevenths and longer notes. Hat/percussion ornaments remain sparse.
HOLD SEQ
The existing overview remains available. K1–K4, ALGORITHM and PRESETS address KK/SD/HH/PR/BS/CH. The first three white keys select P1–P3; the first six black keys select channel. HOME 4/5 is the larger pattern-switching view.
GLO / HOLD GLO
Short GLO presses cycle MIXER/GLOBAL; SELECT changes tempo without a hold. Held GLO retains six level encoders, black-key mute and white-key momentary solo, plus E4 unmute all, F4 fill, G4 tap tempo. GLO + OCT− reloads its mixer snapshot. Channel delay/reverb/chorus settings are in FX.
LFO / FX → FIRST PAGE → OCT+
Randomise both LFOs and modulation routes from LFO’s first page, or channel effects from FX’s first page. Dedicated FX generation has a clearly audible lead processor and bounded feedback. Melodic channels avoid a random slicer; the complete manual effects remain available. Hold SAVE for undo.
SEL → SCALE
K1 NOTES/CHORDS; K2 root; K3 scale; K4 quantisation. All 35 scales remain available, including the supplied Ableton Scale reference names. SEL page 2 sets chord shape, voicing and transpose. QUANTIZE OFF allows chromatic custom chords. Mode changes retain pattern notes and release already-held notes correctly.
ENV → CH RELEASE
Only CH boots with 2BAR release, including restored sessions. All ten CH factory presets start there. Release follows tempo even with ENV SYNC off; attack/decay remain milliseconds unless ENV SYNC is on. Random sound preserves the selected release, including a manual change. CH has a strict maximum of four active voices, including held notes and release tails, in both NOTES and CHORDS. One chord can contain three or four notes. When all four voices are occupied, incoming notes replace existing voices; previous release tails can therefore end before their selected 2BAR duration. Other channels and the shared 8/12-voice budget remain unchanged. Hardware CPU overload can interrupt a voice; a displayed release alone does not establish that audio deadlines were met.
SAVE / TEMP SAVE / CONTROL ALL
SAVE’s PROJECT pages save permanently. GLO + SAVE makes a RAM snapshot; GLO + HOME reloads it; GLO + OCT+ reloads the selected channel. GLO + EDIT + K1–K4 changes included channels together; GLO + EDIT + OCT− toggles inclusion. RAM snapshots disappear after power-off.
EDITORS / SYSTEM → READABLE TEXT
Outside the five custom HOME pages, labels, values, headings, dialogs and bottom hints use enlarged pixel text. System settings show three tall rows at a time, with each label above its value. PRESETS scrolls through every row; ALGORITHM changes tab and OCT± changes the value or opens the selected action. The full settings and synthesis controls remain available. All eight Undo history entries remain.
HOME HELD → SYSTEM → CPU
Both cores are enabled by default. The once-only migration preserves later explicit one-core choices and the hardware fault fallback. Core settings apply after restart. CPU percentage includes nested interrupt time and is averaged; a value below 100% cannot exclude short deadline overruns. The suffix L counts missed audio-buffer deadlines since boot (display capped at 999): L0 means none recorded, a rising number proves missed deadlines. The per-boot L count restarts at zero even after a warm restart; retained crash counters remain separate. Oscillators and the synth envelope execute in fast RAM. Scheduling anticipates newly allocated voices before the two-core split; a silent held voice is not a new onset. Check this on the actual FM-1; browser performance does not measure its load.
SYSTEM → AUDIO TIMING
Read-only rows after CPU CLOCK report hardware timing. AUDIO PEAK is the maximum measured buffer duration since boot, including nested interrupts; 100% uses the approximately 5.8 ms buffer deadline. AUDIO LAST is the latest missed buffer duration, or the busiest buffer before the first miss. CH SYNTH, CH FX/MIX, CORE1 WAIT and AUDIO IRQ show microseconds for that same buffer: CH voice processing, its remaining channel processing, the main core’s wait for the worker, and nested timer-interrupt time. These wall times can overlap, so do not add them as separate CPU percentages. Later clean buffers retain the most recent failure’s stage snapshot. Restart resets the readings. The browser cannot emulate hardware timings. The target keeps the exact sine/filter/saturation tables in RAM alongside oscillator/envelope code.
USB DIAGNOSTIC CONSOLE
The USB console records CPU, missed buffers and saved timings from rc9 or rc10. rc10 adds timings and core assignment for all six tracks, serial mixer work and interrupt-aware scheduling. rc9 continues to work without reflashing. A zero CPU MHz report means the clock source was not recognised. Use desktop Chrome/Edge, enable HOME held → SYSTEM → USB SERIAL → ON, wait for USB to reappear if needed, then connect the serial port. Play a clean baseline without CH, enable CH, mark audible rasp moments, stop, let one more sample finish, pause capture, then save the JSON log. Polling is serialized and low-rate; no MIDI/audio recording or installation is started. The log stays local and includes sound names and notes you enter. The page explains sampling and firmware-map limits.

Up to 64 steps per pattern, three performance positions P1–P3 per channel. The compatible legacy storage format and 64-pattern shared pool are retained for backups. Stop playback if the finite deferred-save queue asks for space.
