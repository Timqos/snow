INSIDE SNOW

Made for hands-on sound.

One role. Many voices.

Kick · Snare · Hat · Percussion · Bass · Chord. Each channel starts with ten factory sounds and stays its own instrument. Go much further with three oscillators, FM pair/chain/parallel, ring, additive and fold algorithms; sine, triangle, saw, square, pulse and organ waves.

Full amp ADSR, pitch/FM envelopes, filters, two LFOs and modulation are available from 27 EDIT pages. Percussion can play pitched notes; bass follows your line, and chords keep their polyphonic body.

A new sound, with a backbone.

On the first EDIT page, OCT+ creates a fresh instrument sound. It coordinates oscillator ratios, register, envelopes, filtering, modulation and effects instead of throwing every control to an unrelated extreme.

Chords stay playable chords. Bass keeps its low end. Drums keep their attack and body. Sounds are generated from a large parameter space, rather than cycled through the factory presets. Hold SAVE to undo.

Patterns that keep moving.

GEN RND creates new rhythm, notes and velocities. GEN PARM adds new parameter locks to the existing notes. PARM AMT controls their amount and depth; CLEAR removes steps and locks.

Each role gets its own phrasing. Musical influences mix inside the generator without a genre menu. Pitched parts respect the scale, and hats/percussion can add rare retriggers and triplets. EVOLVE refreshes phrases as they play.

Space for every channel.

Independent delay, reverb and chorus settings and tails on all six channels. Tape, bitcrush, drive and insert effects add colour. Smart sound generation keeps the dry instrument in front and avoids piling up extreme processing.

A pixel interface, ten system colours and value-linked icons keep the instrument readable. HOME concentrates on one selected instrument with direct synthesis, generation and mix controls. MIXER and PATTERNS show all six channels together. The channel DJ filter and stereo width include the channel’s effect returns.

FIRST FIVE MINUTES

Start on HOME.

  1. Switch on the simulator. Drag an encoder up/down, use the piano keys, and press the hardware-style buttons. Shift-click holds a button down.
  2. On HOME, use ALGORITHM to choose KK, SD, HH, PR, BS or CH. PRESETS chooses one of that instrument’s ten factory sounds; its name appears above the main icon.
  3. Turn SELECT one click right from the left-arrow position. All three arrows point right: the generation panel is active. Turn K2 one detent to create a phrase and parameter locks together, then press PLAY/STOP. Each further detent, in either direction, creates another result.
  4. On that same panel, K1 generates a new instrument sound, K3 generates LFO settings and K4 generates effects. Hold SAVE to undo the last action.
  5. Turn SELECT left for the four synth macros, or right to the up-arrow position for VOL / PAN / FLR / WDT. HOME SELECT never changes BPM. Tap GLO to use the existing tempo controls; keeping GLO held is not required for its normal window.

The simulator runs the firmware’s C synthesis and interface through WebAssembly. Browser saves stay on this computer. It does not emulate the physical USB audio, MIDI output or TRS ports.

INSTALL / RETURN TO FACTORY
Read the risk and responsibility notice, back up before writing, and retain the matching original package. The installer guide includes step-by-step Snow installation and factory return. The original V15/V16 bootstrap determines which factory version is compatible; do not assume the latest file is suitable. Snow’s own installer accepts Snow only. Restore each firmware’s backups with that firmware’s matching tools.
HOME → SELECT
One selected channel, its preset name, active pattern and the output waveform. SELECT has three bounded positions: left arrows = SYNTH, right arrows = GEN, up arrows = MIX. All three arrows turn together. K1–K4 control only the active panel. Focus stays the same when changing channels. Ordinary OCT± presses change octave immediately, including on the GEN panel; CH’s HOME+OCT+ combination is described below. Hold HOME for settings, including display colour.
HOME → SYNTH ←
K1 TONE, K2 SHAPE, K3 SWEEP, K4 DECAY. The left readout shows the last synth macro you touched, its percentage and a pixel progress bar. The preset name stays directly below it. Channel and generator icons retain their reference shapes and fixed positions; local pixel details follow knob values or generation events. There is no continuous idle animation.
HOME → GEN →
One encoder detent in either direction = one generation, without acceleration. K1 GN/PRM: the same smart sound generator as EDIT page 1. K2 GN/SEQ: the existing phrase generator followed by parameter-lock generation; one held-SAVE undo restores notes and locks together. The random stream keeps advancing, so generating again after undo gives a fresh result. Uses the channel’s current density, scale and PARM AMT; PARM AMT = 0 disables generated locks. K3 GN/LFO: the LFO generator. K4 GN/FX: the FX generator. HOME generation always targets the selected channel; SEQ’s ALL target remains available in its own menu. Pending pattern launches must finish before generating another phrase.
HOME → MIX ↑
K1 VOL: channel level. K2 PAN: left/right, centred at 50%. K3 FLR: DJ filter; 50% is neutral, lower positions cut high frequencies, higher positions cut low frequencies. K4 WDT: stereo width of the channel including its effect returns; 0% folds to mono, 50% preserves normal stereo, 100% doubles the side component. Width does not invent stereo in a purely mono source; SPREAD and stereo effects can provide that content. Filter/width controls are smoothed, and their neutral defaults preserve the original audio path. Final PAN remains independent of width.
CH → HOME + OCT+ → N/CHO
On CH’s HOME, hold HOME and press OCT+ once to toggle N (NOTES) / CHO (CHORDS). Keeping OCT+ held does not repeat. This combination changes neither octave nor panel focus; releasing HOME afterward does not open settings. Ordinary OCT+ remains immediate octave-up. Holding HOME without the combination still opens system settings. The pixel switch under the cassette and SEL page 1 share the same per-channel mode. NOTES plays individual keys so you can record your own chords; CHORDS expands one key to the chosen chord. Held notes still release correctly after changing mode.
ALGORITHM / PRESETS / SELECT
ALGORITHM chooses channel; PRESETS browses its factory sounds. SELECT chooses panels on HOME and retains its existing page/tempo behaviour elsewhere. The panel arrows or current page identify what K1–K4 control.
EDIT → MACROS → OCT+
Generate a new sound across all EDIT pages of the selected channel. Instrument identity, sequence and other channels stay intact. Hold SAVE for undo. OCT+ on other EDIT pages keeps its normal action.
SEQ → SEQ GEN
OCT+: GEN RND. OCT−: GEN PARM. SAVE + OCT−: CLEAR. K1: selected channel / ALL; K2: density; K3: variation; K4: parameter-lock amount. SELECT opens the remaining generation pages.
HOLD SEQ
All six pattern columns. K1–K4 select the first four channels’ patterns; ALGORITHM selects bass patterns and PRESETS chord patterns. OCT± switches A–H / I–P. Black keys select a channel; white keys select its pattern. Launches are quantized during playback.
HOLD GLO
Six channel levels: K1–K4, ALGORITHM and PRESETS. The first six black keys mute; the first six white keys solo while held. E4: unmute all. F4: fill. G4: tap tempo. The existing held-GLO tempo gesture also remains available; GLO + OCT− restores the mixer snapshot. For ordinary GLO-window tempo control, tap GLO and turn SELECT with the existing BPM-lock preference; no button hold is required.
LFO → FIRST PAGE → OCT+
Randomise both LFOs, their timing/sync, depths and modulation routes for the selected channel. All LFO pages participate. Hold SAVE to undo.
FX → FIRST PAGE → OCT+
Randomise all effect pages for the selected channel: delay, reverb, chorus, drive, insert, Tape, bitcrush, slicer and ducking. Feedback and wet levels stay bounded. Hold SAVE to undo, including slicer and duck settings.
SEL → SCALE
K1: CHORDS / NOTES, also available under CH’s cassette on HOME; K2: root; K3: scale; K4: quantisation. All 35 scales include the Ableton Scale names shown in the reference, with the full name below the keyboard. NOTES plays each key as one note: play and record your own chords, up to four notes on CH. Use QUANTIZE OFF for chromatic chords. CHORDS expands one key using the shape and voicing on SEL page 2; transpose is also on page 2. Changing mode leaves existing pattern notes intact. New generation creates single notes in NOTES or diatonic chords in CHORDS.
ENV → CH RELEASE
The CH channel starts at 2BAR release on all ten factory sounds. It follows tempo even with ENV SYNC off; attack and decay stay in milliseconds unless you enable ENV SYNC. EDIT → OCT+ keeps the release, including any manual adjustment. Other channels keep their original envelope behaviour.
SAVE / TEMP SAVE
Use SAVE’s PROJECT pages to store a project. GLO + SAVE takes a temporary RAM snapshot; GLO + HOME reloads it, and GLO + OCT+ reloads the selected channel. Temporary snapshots disappear after power-off.
CONTROL ALL
GLO + EDIT + K1–K4 changes the included channels together. GLO + EDIT + OCT− toggles the selected channel’s inclusion. A sound generated by RANDOM EDIT keeps its role; manual editing can still take it far beyond that starting point.

Up to 64 steps per pattern, 16 pattern positions per channel and a shared pool of 64 unique patterns. The deferred-save queue is finite; stop playback if the device asks for space to save.

Open source, in progress.

Snow builds on Skiff and Felucca. The firmware and simulator share the same sound engine. Development and software testing continue; hardware validation is still required.
